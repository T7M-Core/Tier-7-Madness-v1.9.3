# Tier 7 Madness
Code of the simple rumble-based mod - Tier 7 Madness (T7M for short).
This is the most recent version of the mod with all of it's content up to v1.9.3. The current plan is slowly developing the v2.0 - a complete remake of the mod, while allowing anyone else to enjoy the legacy version.

Our official discord server contains all of the infromation, which includes full credits, visual ship / map lists and updates on the development, so please consider joining - https://discord.gg/yMbbugh92Q
